#
# WHY THE FLOOR SITS BELOW THE LAST MEASUREMENT. After the keyword-identifier
# fix this reads 86.3% of 5913 lines under g++-13, the compiler available where
# it was run. CI measures with g++-14, which counts a slightly different set of
# lines - that discrepancy has already turned one job red over a single tenth of
# a percent. So the floor stays at 86.2: it is a floor, and a floor set exactly
# at one compiler's reading is a floor that flaps. Raise it when a change moves
# the number by more than that noise.
#
